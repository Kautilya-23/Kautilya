# Frontend (Angular 17, standalone components)
- Install: `npm install` · Run: `npm start` (http://localhost:4200) · Build: `npm run build`
- API base URL: `src/app/services/api.service.ts` (`http://localhost:8080/api`). Backend must be running.
- Structure: `pages/` (Patients, Appointments, Consultation), `services/` (PatientService, AppointmentService, ConsultationService, `errorMessage` helper), `models/`.
